# 赛程手动导入（FIFA 官网 · 中文）

赛程数据来自 [FIFA 2026 赛程页](https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/scores-fixtures)，队名为中文。

**开球时间**：英文站页面的「日期 + 钟面时间」加 **9 小时** 得到 **北京时间**，再存为 UTC；前端按 `Asia/Shanghai` 显示。不要用球场当地时区直接换算（会比中国区官方表晚数小时）。

## 1. 生成 / 更新种子文件

```bash
python3 scripts/import_fifa_matches.py
```

输出：`seeds/matches.json`（当前 **104 场**：72 小组赛 + 32 强 + 16 强 + 8 强 + 2 半决赛 + 三四名 + 决赛）。

修改赛程时编辑 `scripts/import_fifa_matches.py` 中的 `RAW` 列表后重新运行上述命令。

## 2. 写入数据库

```bash
./start.sh seed
```

- **新场次**：按 `id`（`fifa-<官网比赛ID>`）插入。
- **已有场次**：更新队名、开球时间、`data_version` 等（可重复执行）。

若服务器上仍有旧的演示 ID（`wc2026-*`），可清理后再导入：

```sql
DELETE FROM matches WHERE id LIKE 'wc2026-%';
```

## 3. 验证

```bash
curl -s http://127.0.0.1:8000/api/matches | python3 -c "import sys,json; print(len(json.load(sys.stdin)))"
# 应约为 104
```

## 4. 字段说明

| 字段 | 说明 |
|------|------|
| `id` | `fifa-400021443` 等形式，与官网 match-centre 数字 ID 对应 |
| `stage` | `group` / `round32` / `round16` / `quarter` / `semifinal` / `third_place` / `final` |
| `group_code` | 小组赛 A–L，淘汰赛为 `null` |
| `kickoff_at` | ISO UTC，前端用 `zh-CN` 显示本地时间 |
| `is_hot` | 开幕战、若干焦点战、半决赛、决赛等为 `true` |

淘汰赛占位队名示例：`A组第1名`、`16强第89场胜者`、`半决赛101胜者`。

## 5. 数据概览（football-data.org）

赛程导入后，可用 API 拉取真实基本面写入 `match_facts`，见 [football-data-sync.md](./football-data-sync.md)：

```bash
./start.sh sync-facts
```
